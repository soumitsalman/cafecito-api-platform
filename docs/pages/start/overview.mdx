# Cafecito APIs & MCPs

Choose the product that matches the job you need to do. Every live product uses the same API key and gateway base URL: `https://api.cafecito.tech`.

**Live:** Beans and Espresso. **Future:** Cortado and Latte.

## Products

| Product | Status | Features |
| --- | --- | --- |
| [**Beans**](/products/beans) — News and publisher content | Live | Beans is a publisher-content API for news, blogs, financial and earnings reports, litigation and lawsuits, official statements, research, technical documents, and related coverage context. |
| [**Espresso**](/products/espresso) — Market and business intelligence | Live | Espresso is a market, business, event, and news intelligence API for searching concrete Events, interpreting Signals, and tracing evidence and Sources. GDELT and Perigon are comparison patterns, not claims of route-for-route equivalence. |
| [**Cortado**](/products/cortado) — Social media automation | Coming soon | Cortado is a future social-media management API. It has no public REST or MCP surface. |
| **Latte** — Reserved product | Coming soon | Latte is a reserved future travel scheduler API. It has no public REST or MCP surface. |
