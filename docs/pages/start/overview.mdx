# Cafecito APIs

Choose the product that matches the job you need to do. Every live product uses the same API key and gateway base URL: `https://api.cafecito.tech`.

## Products

| Product | Status | Features |
| --- | --- | --- |
| **[Beans](/products/beans)** News & Blogs | <Badge className="badge-live">Live</Badge> | The Beans API is a read-only API providing searchable and filterable access to publisher Articles, Sources, Stories, feeds, and coverage context. |
| **[Espresso](/products/espresso)** Business intelligence | <Badge className="badge-live">Live</Badge> | The Espresso API is a read-only API providing searchable business intelligence through concrete Events, synthesized Signals, evidence, and Sources. |
| **[Cortado](/products/cortado)** Social Media Automation | <Badge variant="secondary">Coming Soon</Badge> | Social publishing, scheduling, and analytics. |

## Start building

1. **[Create an API key](/start/api-keys)**.
2. **[Make your first API call](/start/first-api-call)** with Beans or Espresso.
3. Continue to the relevant product overview for concepts, examples, and next steps.

For AI-agent and MCP clients, see [MCP & AI agents](/guides/mcp-ai-agents). For shared request behavior, see [API conventions](/guides/api-conventions). For current preview limits, see [Pricing and limits](/guides/pricing-limits).
