# API Keys

One Cafecito API key works across the gateway REST APIs and MCP servers.

<Stepper>
1. Go to [API Keys](/settings/api-keys).
2. Create a key and copy it into a secret manager or environment variable.
3. Send it as Authorization: Bearer YOUR-API-KEY.
</Stepper>

## Example

~~~bash
curl -s --get "https://api.cafecito.tech/beans/articles/latest" \
  --data-urlencode "content_type=blog" \
  --data-urlencode "limit=5" \
  -H "Authorization: Bearer YOUR-API-KEY"
~~~

Use separate keys per app or environment, rotate leaked keys, and never commit keys to source control.

The same key works for https://api.cafecito.tech/beans/mcp and https://api.cafecito.tech/espresso/mcp.
