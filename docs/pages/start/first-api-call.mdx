# First API call

Cafecito APIs use the same gateway base URL and Bearer API-key header.

~~~bash
export CAFECITO_API_KEY="YOUR_API_KEY"
export BASE_URL="https://api.cafecito.tech"
~~~

## Beans: retrieve recent publisher Articles

Use Beans when the question needs publisher Article material; this example filters to news.

~~~bash
curl -s --get "$BASE_URL/beans/articles/latest" \
  --data-urlencode "content_type=news" \
  --data-urlencode "limit=5" \
  -H "Authorization: Bearer $CAFECITO_API_KEY"
~~~

The public content_type enum includes all stored types listed in the Beans overview; this example uses news. Continue with the [Beans overview](/products/beans) or [Beans API reference](/api/beans).

## Espresso: find structured developments

Use Espresso when the question is what happened or what it may mean.

~~~bash
curl -s --get "$BASE_URL/espresso/events" \
  --data-urlencode "q=semiconductor supply pressure" \
  --data-urlencode "limit=5" \
  -H "Authorization: Bearer $CAFECITO_API_KEY"
~~~
