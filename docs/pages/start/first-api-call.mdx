# First API call

Cafecito APIs use the same gateway base URL and Bearer API-key header. Create a key first if you do not have one.

```bash
export CAFECITO_API_KEY="YOUR_API_KEY"
export BASE_URL="https://api.cafecito.tech"
```

## Choose a product

### Beans: retrieve recent news and blog articles

Use Beans when you need article-level news intelligence, including search, feeds, trends, and propagation.

```bash
curl -s "${BASE_URL}/beans/articles/latest?tags=us&sources=techcrunch" \
  -H "Authorization: Bearer ${CAFECITO_API_KEY}"
```

Continue with the [Beans overview and quickstart](/products/beans) or browse the [Beans API reference](/api/beans).

### Espresso: find concrete business developments

Use Espresso when you need structured Events, synthesized Signals, evidence, source metadata, or agent-oriented response formats. Start with Events when the question is what happened.

```bash
curl -s --get "${BASE_URL}/espresso/events" \
  -H "Authorization: Bearer ${CAFECITO_API_KEY}" \
  --data-urlencode "q=semiconductor supply pressure" \
  --data-urlencode "limit=5"
```

Continue with the [Espresso overview and quickstart](/products/espresso) or browse the [Espresso API reference](/api/espresso).
