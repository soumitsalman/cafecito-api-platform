## Legal, privacy, and publisher requests

Email [support@cafecito.tech](mailto:support@cafecito.tech) for general or confidential contact and use one of these subjects:

- **Privacy Request**
- **Copyright Notice**
- **Publisher Opt-Out**
- **Correction Request**
- **Publisher Licensing**
- **Abuse Report**
- **Security Report**
- **General Support**
- **Legal Question**

GitHub is only for public software bugs and feature requests. Never post legal, privacy, publisher, security, credentials, or confidential information there. See the [canonical corporate policies](https://cafecito.tech/docs/legal/) for the legal operator and complete request procedures.
