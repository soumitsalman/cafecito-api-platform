# Overview

Browse the interactive reference for each Cafecito API. Pick a product below to explore its endpoints, request/response schemas, and try calls directly from the playground.

| API | Description |
| --- | --- |
| **[Beans API](/api/beans)** | The Beans API is a read-only API providing searchable and filterable access to publisher Articles, Sources, Stories, feeds, and coverage context. |
| **[Espresso API](/api/espresso)** | The Espresso API is a read-only API providing searchable business intelligence through concrete Events, synthesized Signals, evidence, and Sources. |

:::info{title="Need a key?"}
All endpoints require an API key. See the [API Keys guide](/start/api-keys) to create one.
:::
